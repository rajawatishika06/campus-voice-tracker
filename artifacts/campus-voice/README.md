# Campus Voice — Complaint Tracker

This is a Vite + React project prepared from the Gemini-exported React component.

## Run locally
1. Install Node.js (18+ recommended).
2. In this folder run `npm install`.
3. Run `npm run dev` to preview, or `npm run build` to build for hosting.

## Deploy
Import this folder/repository into Vercel or Netlify. Build command: `npm run build`. Output directory: `dist`.

## Important limitations in the current demo
- Complaint data is stored in the browser's localStorage, so changes are not shared between users/devices.
- The sample complaint records are mock/demo data.
- The student/admin switch is a demo UI toggle, not secure authentication or authorization.
- Do not use this as a real campus complaint system or enter sensitive personal information until a secure backend, shared database, and proper authentication are added.
